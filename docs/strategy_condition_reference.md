# 技術指標與策略條件參考

> 目的：記錄本專案提供的**技術指標工具**，與各策略（均線交叉、MACD）所用到的買賣條件，作為教學與分享之用。
> 本檔只描述「指標 / 條件是什麼、怎麼算」，不含實際回測績效與個人操作紀錄。

## 一、技術指標庫

對應 `_01_data/` 的指標模組，皆以 OHLCV 為輸入、輸出對應欄位。

### 趨勢類（`indicators_trend.py`）

| 指標 | 函式 | 預設參數 | 用途 |
|------|------|----------|------|
| 簡單移動平均 SMA | `calculate_sma` | window=20 | 趨勢判斷、均線排列基礎 |
| 指數移動平均 EMA | `calculate_ema` | span=20 | 反應較快的趨勢線 |
| MACD | `calculate_macd` | 快 12 / 慢 26 / 訊號 9 | 動能與趨勢轉折 |
| 布林通道 Bollinger | `calculate_bollinger_bands` | window=20、2 倍標準差 | 波動區間、極值參考 |
| 乖離率 BIAS | `calculate_bias` | window=20 | 價格偏離均線的幅度 |
| 平均趨向指標 ADX | `calculate_adx` | period=14 | 趨勢強度（不分多空），常用來過濾盤整 |
| 拋物線 SAR | `calculate_psar` | 0.02 / 0.02 / 0.2 | 追價停損線；加速因子隨創新極值收緊，可當出場 |

### 動能 / 量能類（`indicators_momentum_volume.py`）

| 指標 | 函式 | 預設參數 | 用途 |
|------|------|----------|------|
| RSI | `calculate_rsi` | period=14 | 超買 / 超賣、動能強弱 |
| KD 隨機指標 | `calculate_kd` | n=9、K 平滑 3、D 平滑 3 | 動能、轉折 |
| 蔡金資金流 CMF | `calculate_cmf` | window=20 | 資金淨流入 / 流出 |
| 能量潮 OBV | `calculate_obv` | — | 量能累積方向 |

### 波動類（`indicators_volatility.py`）

| 指標 | 函式 | 預設參數 | 用途 |
|------|------|----------|------|
| 真實波幅 ATR | `calculate_atr` | window=14 | 絕對金額版；要算停損價請用這個（非 ATR%） |
| 真實波幅百分比 ATR% | `calculate_atr_pct` | window=14 | 以 % 表示的波動度（比例、四捨五入 4 位） |
| 報酬波動率 | `calculate_return_volatility` | window=20、scale=10 | 報酬標準差（縮放後） |
| 唐奇安通道 Donchian | `calculate_donchian` | window=20 | N 日最高 / 最低通道 |
| Supertrend | `calculate_supertrend` | period=10、倍數 3 | 中價 ± n×ATR 的趨勢通道線；翻向可當出場 |

### 型態類（`indicators_pattern.py`）

| 指標 | 函式 | 預設參數 | 用途 |
|------|------|----------|------|
| ZigZag 擺動轉折 | `calculate_zigzag` | pct=2% | 擺動高低點、轉折偵測 |

## 二、均線交叉策略條件

對應 `_02_strategy/ma_strategy/`（單股）與 `_03_multi_strategy/ma_cross/`（多股組合）。
基準策略只有「黃金交叉買、死亡交叉賣」，其餘皆為可疊加的進 / 出場濾網（旗標，預設關）。

### 進場條件（買）

| 條件 | 說明 | 參數 / 常用值 |
|------|------|----------------|
| **黃金交叉**（基準） | 短均線由下往上穿越長均線（短均今天在上、昨天不在） | 短 / 長：50 / 200（可換 21 組） |
| **雙日確認** | 交叉後多等一天，短均**連 2 日**站上長均才進 | — |
| **強 K** | 交叉當日為一根**長紅**（開→收 ≥ 5%）或**跳空**開在短均之上 | 長紅門檻 5% |
| **夾角 > N 度** | 黃金交叉當下，短均與長均的斜率夾角 > 門檻才進（每日 % 斜率當正切換算角度） | 典型 20°；斜率視窗 5 日 |
| **夾角擴大** | 短均的 N 日 % 斜率 > 長均 % 斜率（可要求連 N 日遞增） | 視窗 5 日；遞增日數可設 |
| **盤整過濾（ADX）** | 交叉前一根 K 的 ADX(14) < 門檻才進（趨勢尚未發動） | 門檻 20～25 |
| **多頭排列** | 大方向濾網：**120 日線 > 200 日線 且 收盤站上 120 日線**（固定 120 / 200，不隨交叉期數變動） | — |
| **流動性門檻** | 近 5 日均量 > 門檻才進 | 台股 1,000 張（＝100 萬股） |

### 單均線版額外進場（`single_ma_strategy.py`）

以「收盤上穿單一 MA」為基準的突破型，另有：

| 條件 | 說明 |
|------|------|
| **突破均線**（基準） | 收盤由下往上穿越單一 MA |
| **回踩整理** | 突破前 N 日內，累計達 m 日「當日波動較前日收斂、且收在 MA 下方」才算整理過 |
| **回測支撐反轉** | 突破後回測 MA、再翻上的 pullback-to-MA 進場 |
| 強 K / ADX / 流動性 | 與雙均線版同義，可疊加於突破訊號之上 |

### 出場條件（賣）

| 條件 | 說明 |
|------|------|
| **死亡交叉**（基準） | 短均線由上往下穿越長均線 |
| **跌破短均** | 除死亡交叉外，收盤「由上跌破短均線」也出場 |
| **跌破 MA**（單均線版） | 收盤由上穿越下單一 MA 出場 |

> 多股組合版（`multi_ma_cross.py`）：同樣以黃金交叉買、死亡交叉賣，可選加流動性門檻；差別在多檔共用一份資金。

## 三、MACD 策略條件

對應 `_02_strategy/macd_strategy/single_macd_strategy.py`。MACD 固定傳統參數 12 / 26 / 9。
以下只說明「條件是什麼、怎麼開」；各條件實際跑出的結果請看文章系列。

### 三個基礎方案（進場互斥擇一，各自帶一組原生出場）

| 基礎 | 進場 | 原生出場 |
|------|------|----------|
| **交叉** | 黃金交叉：DIF 由下上穿訊號線 | 死亡交叉：DIF 下穿訊號線 |
| **零軸** | DIF 由下上穿 0 軸（不看訊號線） | DIF 由上下穿 0 軸 |
| **背離** | 純柱狀圖底背離：價創 20 日新低、但 hist 未創新低 | 死亡交叉 |

> 註：柱狀圖 hist ＝ DIF − 訊號線，所以「hist 由正轉負」與「死亡交叉」**數學上恆等**，不另列為變體。

### 進場濾網（疊在選定基礎上，一次一條）

| # | 條件 | 說明 | 參數 |
|---|------|------|------|
| ① | 趨勢強度 | 訊號日 ADX > 門檻才進（過濾盤整） | ADX(14) > 25 |
| ② | RSI 同意 | RSI 低於門檻且較前一日上升 | RSI(14) < 50 且上升 |
| ③ | 放量 | 當日量 > N 日均量的倍數 | 量 > 20 日均量 × 1.5 |
| ④ | 柱狀圖動能 | hist 連兩根遞增 | — |
| ⑤ | 資金流 | 蔡金資金流為正 | CMF(20) > 0 |
| ⑥ | 趨勢過濾 | 收盤站上年線 | 收盤 > MA200 |
| ⑦ | 均線多頭排列 | 短中長均線由上而下排好 | MA5 > MA20 > MA60 |
| ⑧ | 創新高 | 收盤創 N 日新高 | 250 日 |
| ⑨ | 跳空 | 開盤高於昨日最高 | — |
| — | 流動性門檻 | 可成交口徑，只 gate 進場 | 5 日均量 × 股價 > 1,000 萬 |

### 出場方案

**取代型**（把原生出場整條換掉，一次一條）

| 條件 | 說明 | 參數 | 切換位置 |
|------|------|------|----------|
| 頂背離 | 價創 20 日新高、但 hist 未創新高 | 20 日 | `sell_signal` |
| 跌破年線 | 收盤由上跌破 MA200 | 200 | `sell_signal` |
| Supertrend 翻空 | 趨勢通道由多翻空當日 | period 10、倍數 3 | `sell_signal` |
| 拋物線 SAR 翻空 | SAR 由多翻空當日 | 0.02 / 0.02 / 0.2 | `sell_signal` |
| 跌破二十日低 | 收盤跌破前 20 日最低（唐奇安下軌） | 20 | `sell_signal` |
| 頂頂低 | 進場後出現較低的 ZigZag 擺動高點 | ZigZag 2% | `EXIT_RULE`（路徑相依） |

**疊加型**（原生出場留著，額外多一條，先觸發的先算；全部路徑相依，切換位置 `EXIT_RULE`）

| 條件 | 說明 | 參數 |
|------|------|------|
| 吊燈出場 | 收盤 < 進場後最高價 − k×ATR（ATR 取當日） | k = 3 |
| 移動停損 | 收盤自進場後最高價回落 n% | 10% |
| 固定停損 | 收盤 < 進場價 − k×ATR（ATR 取進場判定日，之後不動） | k = 2 |
| 固定停利 | 收盤 ≥ 進場價 ×(1+n) | +20% |
| 時間出場 | 持有滿 N 根 K 強制出場（不含任何市場判斷） | 60 根 |

> 停損停利為什麼是「疊加」而不是「取代」：它們是安全網、不是趨勢判斷。若拿 +20% 停利當**唯一**出場，
> 賠錢的部位永遠不會觸發、不會平倉，整批會從已平倉統計裡消失，算出來的東西沒有意義。

### 怎麼切換（三處註解，一次各開一條）

| 位置 | 管什麼 |
|------|--------|
| `buy_signal` | 三基礎互斥擇一 ＋ 進場濾網 ＋ 流動性門檻 |
| `sell_signal` | 原生出場／取代型出場（向量化的那些） |
| `EXIT_RULE`（類別屬性） | 路徑相依出場：頂頂低（取代）＋ 五條疊加風控 |

路徑相依的規則要看「進場價 / 進場以來最高 / 已持有幾根」，無法只用向量化欄位表達，
故獨立成 `EXIT_RULE` 並在 `build_signals` 逐根掃描（作法比照 `ma_cross_strategy` 的 CHOCH）。

`--variant` 只決定輸出資料夾，**不會改變行為**，請與註解狀態保持一致。命名慣例
`{基礎}_{優化}_{口徑}`，例：`cross_baseline`、`div_adx25_amt`、`zero_exit_supertrend_amt`。

### 時點與口徑（全策略共用）

| 項目 | 設定 |
|------|------|
| 判定 → 成交 | 訊號日**收盤判定**、**隔日開盤**成交（無 look-ahead） |
| 停損停利觸發 | 一律用**收盤跌破 / 達標**判定，不模擬盤中觸價 |
| 費用 | 台股手續費 0.1425%（最低 20 元）＋ 賣方證交稅 0.3%，成交價過 tick 進位 |
| 流動性門檻 | 開啟與否會讓數字差很多，比較變體時務必兩邊一致 |
